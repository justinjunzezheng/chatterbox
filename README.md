# Chatterbox

Realtime web chat for Vercel and Supabase.

## Vercel settings

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

Environment variables:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

The application intentionally contains no seeded users, fake contacts or sample messages.
